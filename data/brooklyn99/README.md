# Brooklyn Nine-Nine transcript files

Source: Atharva Naik, https://github.com/atharva-naik/brooklyn99-dataset
Original transcript source credited by the repository: https://subslikescript.com/series/Brooklyn_Nine-Nine-2467372
Retrieved October 14, 2026. The 134 JSON files are preserved as downloaded, including the file labeled DUPE. Each JSON contains a list of transcript blocks; these are not verified speaker turns. The repository includes seasons 1–7 with gaps and no season 8.

The analysis excludes season-4/episode-11-DUPE.json because its episode identification is ambiguous. Retained files have no exactly identical full transcripts. The source code's MIT license is included; it does not establish ownership of the television dialogue.
